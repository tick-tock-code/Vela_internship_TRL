# What This Program Does (Plain English)

This program takes the VCBench founder dataset and turns it into a set of
features that a simple model can learn from.

First, it reads the CSV and converts each founder record into a structured
dictionary. Then it builds features in three possible ways:

- **Human features**: the 15 baseline features from the example script plus
  your custom features (QS tiers, exits, tenure).
- **LLM features**: features generated by a language model from training data.
- **Hybrid**: both human and LLM features together.

After that, it saves a feature table to a Parquet file so you can reuse the
extracted features later without recomputing them.

Finally, it trains a logistic regression model in PyTorch to predict success.
It prints performance metrics and shows the feature coefficients so you can
see which features matter most.
